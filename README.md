# Pokédex 🧠⚡
**Vanilla JavaScript Pokédex App**

This project is a Pokédex app built during my Frontend training to practice web development fundamentals such as DOM manipulation, APIs, and responsive UI. It helps you explore Pokémon data (names, images, stats) in a clear UI.

---

## 🧪 Built With

This project was created using:

- **HTML5**
- **CSS3**
- **JavaScript**

---

## 🛠️ Features

✔️ Displays a list of Pokémon  
✔️ Shows Pokémon details (image, name, etc.)  
✔️ Responsive layout  
✔️ Clean UI for learning purposes
